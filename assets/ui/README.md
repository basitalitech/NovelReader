# Interface artwork

[moonlit.png](moonlit.png) is the packaged Home background (959 × 540 PNG,
about 405 KiB on disk, about 2 MiB decoded). It was generated for this project
with the built-in imagegen tool, then resized for the Vita. The scene is purely
decorative; navigation, cards, status indicators, covers, and text are native
vita2d controls. The application remains usable if the asset cannot load.
Imported EPUB covers remain the publication's own artwork. Books without covers
receive native title cards; no sample novels are added to the user's library.

Generation prompt:

> Use case: illustration-story. Asset type: background artwork for a native PS Vita ebook reader home screen. Create a wide 16:9 dark purple moonlit landscape illustration matching the reference design described here: charcoal and deep aubergine sky, a large softly luminous pale lilac full moon in the upper right, very sparse tiny stars and soft violet clouds, layered silhouetted distant mountains along the lower right, a large black tree entering from the right edge, beneath it on a sloping hill at the far right a small silhouette of a young person sitting and reading an open book. Restrained flat illustrated shapes with soft atmospheric gradients, elegant quiet nighttime mood. Composition: leave the entire left 55 percent and lower left mostly empty dark charcoal #17151f for UI overlays; all recognizable artwork should stay in the rightmost 40 percent. No text, no interface, no device frame, no border, no watermark. This is just the background scene; the app draws its own UI.
